 PARTE 2 — COMANDOS POR GESTO (main.py → brain.py)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Detecção: MediaPipe Hands → gestures.py (análise de dedos) → main.py (mapeamento)
Cada gesto requer CONFIRMACAO_FRAMES=2 frames seguidos para ativar.

 LEGENDA DOS DEDOS:
   P = Polegar | I = Indicador | M = Médio | A = Anelar | Mi = Mínimo
   est = estendido | dob = dobrado

─────────────────────────────────────────────────────────
 GESTOS FORA DO MODO MOUSE (padrão)
─────────────────────────────────────────────────────────

[Gesto "1"]  — I(est) M(dob) A(dob) Mi(dob) P(dob)
  → Volume DOWN (pyautogui.press('volumedown'))

[Gesto "2"]  — I(est) M(est) A(dob) Mi(dob) P(dob)
  → Conectar WoMic (celular como microfone via WiFi)

[Gesto "3"]  — I(est) M(est) P(est) A(dob) Mi(dob)
  → Ligar voz do JARVIS (voz_ativa = True)

[Gesto "4"]  — I(est) M(est) A(est) Mi(est) P(dob)
  → Desligar voz do JARVIS (voz_ativa = False)

[Gesto "5"]  — TODOS estendidos (mão aberta)
  → (sem ação mapeada no process_command)

[Gesto "6"]  — Mi(est) I(dob) M(dob) A(dob) P(dob) (só mindinho)
  → TOGGLE bloqueio de gestos (modo segurança on/off)

[Gesto "7"]  — I(est) P(est) M(dob) A(dob) Mi(dob)
  → TOGGLE modo mouse (controle de cursor por mão)

[Gesto "DB"] — P(est) I(dob) M(dob) A(dob) Mi(dob) (só polegar)
  → Tela cheia (pyautogui.press("f"))

[Gesto "Mute"]    — TODOS dobrados (punho fechado) + debounce 2s
  → Toggle mute do sistema (pactl)

[Gesto "Rock"]    — I(est) Mi(est) M(dob) A(dob) P(est) (chifres)
  → Abrir VS Code (os.system("code"))

[Gesto "Encerrar"] — M(est) I(dob) A(dob) Mi(dob) P(est) (dedo do meio + polegar)
  → Desligar computador (poweroff)

 GESTOS NO MODO MOUSE (gesto "7" ativo)
─────────────────────────────────────────────────────────

Quando modo mouse está ATIVO, a mão controla o cursor:
  → Landmark 10 (base do dedo médio) rastreia posição
  → Suavização com SMOOTHING_FACTOR = 0.25

Os gestos mudam de função no modo mouse:

[Gesto "1"]     → Volume DOWN (igual)

[Gesto "Next"]  → I(est) M(est) A(est) Mi(est) P(dob) → Próxima faixa (Shift+N)
[Gesto "Pause"] → TODOS dobrados (punho) → Play/Pause (Space)
[Gesto "9"]     → M(est) I(dob) A(dob) Mi(dob) P(est) → Sair do JARVIS

 PARTE 4 — SISTEMAS DE SUPORTE (módulos auxiliares)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

─── voice.py (TTS) ───────────────────────────────────────
  • Motor: edge-tts (Microsoft Azure Neural) + mpv
  • Voz: pt-BR-AntonioNeural (+40% velocidade)
  • Streaming: chunks MP3 via pipe direto ao mpv (~300ms latência)
  • Fallback: salva MP3 em disco → toca com mpv
  • Registra toda fala na memória (memory.py)

─── listen.py (Escuta) ───────────────────────────────────
  • Wake word: "Jarvis" via Porcupine (Picovoice)
  • STT: Whisper (faster-whisper, modelo "small", CPU, int8)
  • Auto-detecção microfone: WoMic (celular WiFi 48kHz) ou PC (16kHz)
  • Resample automático 48kHz→16kHz quando usando WoMic
  • Debounce de comandos: 1.2s entre repetições
  • Similaridade mínima para intenção: 0.40
  • Early-exit quando score ≥ 0.85

─── vision.py (Visão) ────────────────────────────────────
  • API: Groq Vision (llama-4-scout-17b-16e-instruct)
  • Salva frames em ~/Jarvis_frames/ com timestamp
  • Thread-safe: frame atualizado pelo main.py a cada ciclo

─── recording.py (Gravação) ──────────────────────────────
  • Vídeo: cv2.VideoWriter (codec mp4v, 20fps)
  • Áudio: sounddevice (44.1kHz, mono, int16)
  • Junção: ffmpeg (vídeo + áudio → mp4 final)
  • Duração máx: 5 minutos, aviso aos 4min30s
  • Fallback: vídeo mudo se áudio/ffmpeg indisponível

─── memory.py (Memória) ──────────────────────────────────
  • Armazena: jarvis_memory.json (máx 2000 entradas)
  • Registra falas do JARVIS e do USUÁRIO
  • Filtros: hoje, ontem, dia da semana, manhã/tarde/noite
  • Resumo: Groq API gera resumo conversado

─── notes.py (Anotações) ─────────────────────────────────
  • Armazena: jarvis_notes.json (máx 500 notas)
  • Tipos: nota (simples) e lembrete (com horário)
  • Lembretes usam threading.Timer para avisar
  • Apagar usa Groq para desambiguação quando necessário

─── file_manager.py (Arquivos) ───────────────────────────
  • Busca recursiva em ~/ com fuzzy matching (SequenceMatcher)
  • Score mínimo: 0.6 para considerar match
  • Abertura com app correta: xdg-open, wine, bash, python3, etc.
  • Listagem: categoriza por tipo + resumo via Groq

─── personality.py (Personalidade) ───────────────────────
  • Gera respostas humanizadas e sarcásticas via Groq
  • Cache com TTL de 1 hora (hash MD5 do contexto)
  • Categorias: saudacao, sucesso, erro, nao_encontrado,
    acao_andamento, aguardando, status, clima, timer, notas, memoria

─── utilities.py (Utilidades) ────────────────────────────
  • Clima: API Open-Meteo (cache 10 min)
  • Timer: threading.Timer com suporte a nomes
  • IA: Groq (llama-3.1-8b-instant) com streaming opcional
  • Parser de duração por voz (extenso + numérico)

─── emotions.py (Emoções) ────────────────────────────────
  • Sistema emocional para animação visual do JARVIS
  • Modo visual muda baseado em interação e hora do dia

─── graphics.py (Interface Visual) ───────────────────────
  • Desenha avatar do JARVIS no frame (OpenCV)
  • Animação de "boca falando" sincronizada com TTS
  • Painel de comandos semitransparente
  • Landmarks customizados das mãos
